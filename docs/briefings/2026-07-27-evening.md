## Let's Talk — Operator Session Notes

- **Symptom**: “audio could not be decoded” on phone — root cause was
  **OpenAI `insufficient_quota`**, not bad audio. Misleading error message
  improved to surface quota when applicable.
- **Fix chosen**: Option 3 — server **whisper.cpp** STT, client **TTS** (no
  cloud speech spend). Env in `.swarmforge/swarm.env`:
  `LETS_TALK_AUDIO_ENGINE=local`, `LETS_TALK_SPEECH_LANGUAGE=auto`,
  `WHISPER_MODEL_PATH=~/.swarmforge/models/ggml-base.bin`.
- **French**: multilingual model required (`base.en` is English-only). Auto mode
  detects language from transcript; each turn returns `speechLocale` (`fr-FR` /
  `en-US`) so the phone picks the matching installed voice.
- **Launch**: `./swarmforge/scripts/start_bridge_headless.sh <root> 8765`
- **Tunnel**: `https://lovers-developments-duties-handled.trycloudflare.com`
  (console → Let's Talk; `?bearer=` from `.swarmforge/operator/bridge-token`).
