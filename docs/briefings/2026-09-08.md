## The story of this window: a land-step attribution bug cascade, found and closed in one day

Yesterday's BL-1348 spec-gap bounce (an omission bounce, meant to revert
nothing) instead ran the generic revert path and silently stripped ruling
B's implementation, tests, both vitest configs, and two other tickets'
evidence off the QA branch — caught only because the coder restoring them
on merge noticed the gap. Chasing that one incident to ground uncovered a
chain of ten related defects in how the land step attributes paths to
tickets, all closed today:

- **BL-1471** — a bounce revert now touches only the bounced ticket's own
  paths, and an omission-class bounce (nothing to revert) reverts nothing
  at all.
- **BL-1472** — a revert or its reapply is now transparent to path
  attribution: the paths it undoes or redoes belong to the commits it
  undoes or redoes, not to whichever ticket's land happens to carry them.
- **BL-1473** — a replay can no longer propose deleting or resurrecting a
  path the parcel's own commits never touched (its own-paths diff had
  been comparing against the wrong base and was about to delete two
  freshly minted tickets).
- **BL-1474** — a replay that fails to commit now reports the guard's own
  refusal reason instead of a generic "nothing to commit."
- **BL-1446** — the land step's bounded walk now starts from the last
  *landed* boundary, not the last handoff, so a routine main sync no
  longer manufactures a false entanglement.
- **BL-1447** — a replay missing any path the parcel actually changed is
  now refused before it publishes, instead of shipping incomplete.
- **BL-1461** — a tip carrying a sibling's unlanded work absorbed before
  the parcel's last hop is no longer waved through as `LAND_CLEAN`.
- **BL-1463** — an escalating land step now always names the sibling it
  couldn't read, instead of escalating silently.
- **BL-1465** — the BL-1375 passenger property now asserts the sequencing
  the landed BL-1447 code actually uses, instead of the pre-BL-1447 shape
  (it had been failing every `extension/src` commit swarm-wide).
- **BL-1466** — a sibling that was bounced but not yet re-fixed can no
  longer ride another ticket's land as an approved passenger.
- **BL-1470** — the bounce-blocking check now reads the bounce store from
  the shared root every caller actually writes to, instead of silently
  answering "never bounced" from an empty worktree-local path.

None of these were caught by a green suite — each surfaced from a human or
coder reading an actual diff by hand. **BL-1481** (a shared-path refusal
that reads as attribution-only, not a real block) is still paused,
adjudicated by the specifier as a false-block ruling rather than a defect.
