## Business features delivered

**The QA land/replay/reconcile machinery had its worst structural gaps
closed.** This was the largest single theme across both days: a chain of
defects where the pipeline's OWN delivery mechanism — not application
code — was silently dropping or misattributing work.
- BL-1298: the land step's replay couldn't run from any role's own
  worktree at all (a `.git` file, not a directory, broke its scratch
  checkout).
- BL-1332 and BL-1343: the replay's own path-attribution logic could drop
  a landing ticket's own file, or let an unlanded sibling's line ride
  along inside a shared file — in `specs/pipeline/steps/index.js`, the
  second one froze every role's commits.
- BL-1272: a landed sibling kept being reported as still "entangled" long
  after it landed.
- BL-1334 and BL-1339: QA's own just-landed, approved work was reading as
  **unapproved** to every ancestry-based consumer, because the land step's
  tip-pure replay never advanced `swarmforge-QA` — fixed with a durable
  land-approval record, then (same day) fixed AGAIN because the record was
  written into the writer's own linked worktree while every reader
  resolved the shared target root, so the first fix shipped fully gated
  and inert until BL-1339 corrected the root.
- BL-1310: reconcile guards narrowed WHEN a discard could happen but none
  made it recoverable — committed work could survive only as unreachable
  reflog objects.
- BL-1341: a hand-resolved merge on `main` could silently drop QA-landed
  work because the merge-deletion guard only ever looked at the outgoing
  side of a merge.
- BL-1306 and BL-1338: the handoff-audit challenge and the routing-stamp/
  adjudication fingerprint each had a self-defeating scope bug (stored
  under one key, looked up under another; the stamp invalidating the very
  adjudication that authorized it).
- BL-1314: a BL-925 invariant assertion greped `handoffd.bb` for ANY
  ancestry call at all, so two legitimate helpers unrelated to the
  predicate it was meant to guard failed an invariant that was actually
  intact.
- BL-1323 (stamp-off): certifies the operator's own main-sync-deadlock
  hotfix, which teaches `./swarm heal` to name overlapping paths instead
  of a bare "dirty" report — and BL-1333 is today's follow-on stamp-off
  for the hotfix that lets the reconcile daemon auto-drop a dirty path
  once it's proven byte-identical to `origin/main`.
