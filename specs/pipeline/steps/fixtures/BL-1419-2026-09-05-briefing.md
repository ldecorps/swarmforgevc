## Business features delivered

**The QA land/replay/reconcile machinery kept absorbing structural
gaps** — the same theme as 2026-09-03, continuing deeper into the same
mechanism:
- BL-1309: the one landing step QA cannot skip never asked what the tip
  actually carried, so a plain push of the QA branch shipped every ticket
  previously merged into it.
- BL-1374: a routine `git merge main` named after a ticket credited that
  ticket's replay with every passenger the sync merge carried, sweeping
  other tickets' unlanded files into paths it never actually touched.
- BL-1389: a path an unlanded sibling owns alone could still ride another
  ticket's land — the tip-pure replay now excludes it regardless of the
  sibling's approval state.
- BL-1385: a step handler that fails to load can no longer reach `main` —
  the land tree guard and the commit guard now prove every discovered
  handler's module graph resolves on the tree under test (one unloadable
  handler had been crashing every acceptance run under discovery).
- BL-1391: the reconcile sweep now resolves a conflict confined to
  append-only bookkeeping files deterministically instead of refusing and
  waiting on a human for a note or an `abandoned_commits` record two roles
  both appended.
- BL-1390: a commit on the shared main checkout is now pushed at once
  while it still fast-forwards, so local `main` stays at ahead-zero and
  every QA landing absorbs by fast-forward instead of a merge nobody is
  allowed to make.
- BL-1386 and BL-1387: the reconcile sweep never orphans a merge it
  started (it aborts its own stuck `MERGE_HEAD` next tick and logs the
  real failure reason instead of the word "conflict"), and a merge nobody
  owns is now surfaced as orphaned — never silently held for a human who
  isn't there.
- BL-1359: the Article 4.2 sweep was charging a merge with paths it never
  introduced, because `git diff-tree -m --first-parent` is a no-op that
  reads the union of every parent's diff, not just the first.
- BL-1366: `land_main_publish.sh` documented a lock/decide/rematch/push/
  release caller protocol nothing implemented — QA was hand-orchestrating
  every approval, one slip from a force-push or a stuck lock.
- BL-1360: the ceremony handoff (merge-up broadcast, bookkeeping note) now
  composes its draft from a fixed template instead of every role
  hand-writing and re-reading the protocol before sending.
- BL-1356: stamp-off invariants no longer pin a ledger row's current-state
  literal, which used to jam every role's commit gate the moment the row
  advanced through its own workflow.
- BL-1378 and BL-1376: an expedite-closed ticket can now actually reach
  `backlog/done/` (the close guard used to demand a QA mailbox handoff
  expedite is forbidden from ever placing there), and the expedite closing
  handover now names the branch it left unlanded, instead of going silent
  about the one thing its whole job is to report.
- BL-1379: an expedition used to park every other active ticket into the
  human-held `hold/` folder and never reverse it; the park now reverses
  itself when the expedition lands.
