     `BRIDGE_EXTENSION_HOST_ROOT` to the literal `/home/carillon/swarmforgevc`. That should not
     exist. It is one user's home path inside a product script. On any other host, including
     the macOS host this swarm moved from, the fallback silently does nothing. On this host a
     root without a build silently borrows the live checkout's, which is how this test went
     green-for-the-wrong-reason and then red.

     or to have no default with the operator's env naming it. Raised to the specifier as a note,
     per the ticket.
