## What changed

`swarmforge/scripts/master_main_reconcile_lib.bb`:
- New `current-branch-authorizes-reset?` (true only for `"main"`).
- New `current-branch-via-symbolic-ref` (`git symbolic-ref --short -q HEAD`;
  a non-zero exit or blank output reads as nil, never a guessed branch).
- `refuse-reset-if-local-ahead!` now takes a `:current-branch!` adapter and
  checks it FIRST, before the ahead-count read: any branch other than
  `"main"`, a detached HEAD, an unreadable branch, or an ABSENT
  `:current-branch!` adapter entirely all refuse with
  `{:success false :outcome :not-on-main-refused :branch <name-or-nil>
  :error "..."}` — `raw-reset!` is never called on that path. Grounds and
  outcomes for the existing ahead-count check (`:local-ahead-refused`) are
  unchanged, reached only once the branch check passes.
- `real-git-reset-adapters` now also supplies `:current-branch!`, built
  from the same `:sh!` adapter every other read already uses.

`swarmforge/scripts/handoffd.bb`, `swarm_heal.bb`,
`post_hotfix_merge_origin.bb`: each of the three production call sites now
reads its OWN checkout's branch (mirroring how each already reads its own
ahead-count) and passes it as `:current-branch!` into the same
`refuse-reset-if-local-ahead!` call. `handoffd.bb` also logs a
`not-on-main-refused` line, the same posture as its existing
`local-ahead-refused` log line.
