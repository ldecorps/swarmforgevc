## A real shallow-merge bug found and fixed before it shipped

`evaluate-claim-idle-signal`'s own `(merge default-config config)` is a
SHALLOW merge: handing it a `config` whose `:role-idle-timeout-ms` is an
empty (or partial) map — exactly what `parse-claim-idle-timeout-role-
minutes-ms` returns when the conf carries no line, or a line for a
DIFFERENT role — would silently REPLACE the whole built-in map, hardender's
built-in 90 minutes included, rather than layer on top of it. Caught before
committing: `test/chase_sweep_test_runner.bb`'s first draft passed the
parsed map straight through with no merge, and a new regression case (test
12b in `test_claim_progress_sweep.sh` below) — hardender's fallback with an
unrelated QA conf line present — failed against that draft. Fixed at BOTH
the real call site (`handoffd.bb`'s `claim-idle-timeout-role-minutes-
config` already merged correctly) and the test harness (now merges the
same way), so this gotcha is closed wherever this shape is built, not
only in production code.
