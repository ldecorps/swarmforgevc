## What changed

`extension/test/draftPathUnder.property.test.js`'s invariant-1 property
draws four segments (rootSegment, prefix, tmpdirASegment,
tmpdirBSegment). The root and both TMPDIR segment generators could draw
`.` or `..`; `path.join` then collapses that namespace (a `..` segment
can collapse it all the way to `/`), so the two namespaces the property
requires disjoint were no longer disjoint on that draw - the "never
under TMPDIR" assertion then failed for a draftPathUnder result that
was actually correct (seed -957004781, counterexample `[" ", " ",
"..", " "]`).

Extended the existing `.filter` on the root, tmpdirA and tmpdirB segment
generators to also exclude the exact strings `.` and `..`. The prefix
generator (a filename part, never a path segment) is unchanged, as are
the property's assertions and run count. `draftPathUnder` itself is
untouched.
