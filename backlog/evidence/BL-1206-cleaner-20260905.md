## Defect: `findUnitLaneNodeTestImports`/`findPropertyLaneNodeTestImports` near-identical tree walks

`jscpd` found 2 clones (7.27% duplicated tokens) within
`extension/test/helpers/nodeTestImportGuard.js` itself: BL-1206 added
`findPropertyLaneNodeTestImports` as a copy of the pre-existing (BL-1220)
`findUnitLaneNodeTestImports`, differing only in which lane predicate it
calls (`isPropertyLaneTestFile` vs `isUnitLaneTestFile`) — the coder's own
comment even acknowledged this ("Same walk shape... the only thing that
differs between lanes is which files qualify") without eliminating it.

**Fix**: factored the shared directory walk into one
`findNodeTestImportsForLane(testDir, isLaneFile)` helper; both public
functions (`findUnitLaneNodeTestImports`, `findPropertyLaneNodeTestImports`)
now delegate to it with their own predicate. No behavior change — the
public API (both function names, both signatures) is unchanged, so nothing
that already calls either function needed updating. `jscpd` confirms 0
clones after the fix; both BL-1220's own pre-existing tests (10/10, 3/3)
and BL-1206's new tests (4/4, 3/3) re-verified green.
