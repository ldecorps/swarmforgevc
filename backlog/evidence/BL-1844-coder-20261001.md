## Bounce fix (architect, D1, invariant-unencoded)

The architect correctly rejected the "no sensible executable encoding"
reasoning above: the invariant is a claim about THIS FILE's own source
text, which the runner can read and assert against itself. Added a
standing self-check near the bottom of the runner (before the report
block): it `slurp`s its own `*file*`, finds every code line containing
`count (:system-prompt` (excluding comments and the self-check's own
diagnostic/filter lines, which would otherwise match themselves), and
asserts each one matches `\(<=?\s*\(count \(:system-prompt` — i.e. sits
directly inside a `<=`/`<` ceiling expression, never a pinned-length
equality. Reruns every time the runner runs.
