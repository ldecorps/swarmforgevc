# BL-1778 — coder pass, 2026-09-26

## What changed

`swarmforge/scripts/local_parcel_driver_lib.bb`:
- Removed `commit-shas-since`/`merge-commit-sha?`/`revert-to-pre-claim!`
  (the old, wider-than-intended revert: `git log <pre-claim>..HEAD` with no
  `--first-parent`, reverting the claim's own two merges with `-m 1` AND,
  one by one, every commit those merges brought in).
- Added `attempt-commit-shas` (`git rev-list --first-parent --no-merges
  <postMergeHead>..HEAD`) and `revert-attempt-commits!`: reverts only the
  attempt's own first-parent, non-merge commits after `postMergeHead`,
  newest first, via `git revert` (never reset). A merge the attempt
  itself made mid-attempt is excluded by `--no-merges` and its content
  kept, per the ticket's own "How".
- `give-up!` now destructures `postMergeHead` (not `preClaimHead`) and
  calls `revert-attempt-commits!` with it. `preClaimHead` stays in the
  persisted state (still captured at claim time, still written by
  `persist-post-merge!`) — kept, per the ticket's "may stay... coder's
  call" — just no longer read by `give-up!`.

Retired (BL-1715's own contract, corrected, never reworded):
- `specs/features/BL-1715-...feature` scenario 03 ("the local seat's tree
  after the give-up matches its tree before the claim") — replaced with a
  retirement comment naming BL-1778.
- Its two now-orphaned step handlers in `bl1715DriverSeatGiveUpSteps.js`
  (grepped first: neither pattern used by any other scenario in the file
  or any other `.feature`).
- The property test's tree-half (`bl1715DriverSeatGiveUp.property.test.js`):
  replaced `revert-to-pre-claim!`'s pre-claim-tree property with one
  covering BOTH BL-1778 invariants over generated claim shapes (no main
  merge / a main merge, crossed with the received commit as a merge
  commit / a fast-forward — all 4 cells reached by construction via
  `assertReachFloor`, floor 2) and generated attempt chains (0-4 plain
  commits). Added a dedicated non-property test for the "How"'s own named
  edge case: a merge the attempt itself made mid-attempt is excluded from
  revert and its content survives. Kept the no-op companion test, retargeted
  at `post-merge-head`.
- `docs/how-to/BL-1697-local-parcel-driver.md`: the give-up paragraph
  (~line 131) now describes the post-merge-tree contract, not pre-claim.
- `docs/diagrams/handoff-flow.mmd`: the give-up comment (~lines 44-48) and
  the `DGIVEUP` node text, same correction (registered diagram, change-
  trigger fired by this parcel).

New: `specs/pipeline/steps/bl1778GiveUpKeepsClaimMergesSteps.js` — builds
each claim-merge shape with plain git calls (never through `seat merge`,
which is always `--no-ff` in production and so can never itself produce a
fast-forward row — the fixture's own job, per the ticket's "How", is to
exercise every shape `postMergeHead` can actually take).
