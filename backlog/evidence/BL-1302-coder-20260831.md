# BL-1302 — coder pass, 2026-08-31

A reverse-hop copy is not a duplicate chain.

## 1. What changed

Three files, one predicate:

- `swarmforge/scripts/handoff_lib.bb` — NEW `handoff-lib/non-forwarding?`.
  One spelling of the marker check, because two callers need it and a marker
  parsed one way in one file and another way in the other is exactly how the
  two disagree. Absence, `false`, `TRUE`, and an empty value are all false;
  only the literal `true` exempts.
- `swarmforge/scripts/duplicate_chain_guard_lib.bb` — `git-handoff-for-ticket?`
  now also requires `(not (handoff-lib/non-forwarding? file))`. A candidate is
  SKIPPED, not the walk aborted, so a genuine competing chain sitting behind a
  reverse copy is still found and named with its `redo_from.sh` advice intact.
- `swarmforge/scripts/swarm_handoff.bb` — `inbound-non-forwarding?` now calls
  the shared predicate instead of respelling it inline. Behaviour identical;
  this is the "reuse rather than respell" the ticket asks for.

No new mechanism, so no `required_wiring` — as the ticket says deliberately.
The predicate sits inside a function `swarm_handoff.bb`'s validate step
already calls on every send.

## 3. Declared invariants (BL-654) — both executable

`swarmforge/scripts/test/bl1302_reverse_copy_not_duplicate_chain_property_runner.bb`
(property lane; a property runner is never a suite-manifest member, so no row
was added — `bb suite_inventory_cli.bb` → `ok - 443 test file(s), 439
standing, 4 excluded`).

Both invariants are pinned by ONE property against an INDEPENDENT oracle:

    guard(population) == legacy(population minus the exempt parcels)

where `legacy-blocking-parcel` reimplements the pre-BL-1302 walk by a
different route. Invariant 1 is the "minus" — an exempt parcel is never the
answer, restated directly as its own assertion so a wrong oracle cannot hide
it. Invariant 2 is the "legacy" — on a population where nothing carries the
marker the two agree exactly, so every pre-existing parcel shape blocks as it
did.

Generator reach is ASSERTED, not hoped for (200 runs, all floors met):

```
REACH some-exempt                       70  (floor 50)
REACH all-live-exempt                   20  (floor 10)
REACH exempt-hides-a-real-blocker       50  (floor 10)
REACH non-true-marker-present          118  (floor 50)
REACH blocked                          118  (floor 50)
REACH unblocked                          82  (floor 50)
```

`exempt-hides-a-real-blocker` is the one that matters: it is the state where
skipping wrongly implemented as aborting would return `nil` instead of the
real blocker. `non-true-marker-present` is invariant 2's floor.

Non-vacuity — two deliberate breaks, each run and restored:

| deliberate break | result |
|---|---|
| exemption removed (the defect itself) | FAILS from run 2, both the oracle mismatch AND invariant 1's direct check |
| exempt on any marker PRESENT (`nil?` on the header) | FAILS from run 9 — absence and `false` stop failing closed |
