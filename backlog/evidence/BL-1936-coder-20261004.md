## The change against the description
`swarmforge/scripts/local_model_tool_call_shim.py` (as landed by e44f9cdfc7,
plus the 2026-10-04 follow-ups already in main):
- `num_predict_of` reads a positive num_predict from an /api/show answer
  (None for absent, -1 or -2).
- `clamp_output_budget` lowers max_tokens and max_completion_tokens above
  the cap and reports the largest value lowered; never raises or adds one.
- `ShimHandler._output_cap` (via `_limits`) asks Ollama's /api/show once per
  model and caches the answer 300 s; a failed lookup is not cached and
  leaves the request as sent.
- Applied in `_complete` (the tool path, nudge included) and in `do_POST`
  for a tool-less chat completion (the passthrough). The log line gains
  `budget=<sent>-><cap>` when a request was lowered.
- The compaction path (`_compact`) additionally caps at
  COMPACTION_OUTPUT_CAP and min's it with the model cap.

## Invariant 2 — never raises or adds a budget; unclamped when no cap
Covered by:
- `test_a_budget_is_never_raised_added_or_read_from_a_bool` (pure helper:
  absent, below-cap, bool, and None-cap all leave the request untouched).
- `test_a_model_with_no_num_predict_keeps_the_client_budget` (live: a model
  with no num_predict keeps the client's 13000).

  only the two budget keys move; the original request is not mutated).

path; it forwards Ollama's answer unchanged.
