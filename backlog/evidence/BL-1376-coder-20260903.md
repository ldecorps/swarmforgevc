## A design point decided inside the ticket, honoured here

An absent branch is a **definite** nothing, not an unreadable check. A run that
refuses before it ever creates a worktree left no code on a branch, and
reporting a phantom leaving in front of every early refusal would be noise —
`test_expedite_cli.sh`'s BL-1024d check ("a refused run that parked nothing
claims nothing") is the standing statement of that, and it stays green.
Scenario 05's refusal-after-parking therefore starts from a branch an earlier
run already left, which is the shape a re-expedite actually has.
