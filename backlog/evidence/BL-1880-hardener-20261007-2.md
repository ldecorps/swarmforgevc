(`referencing "2026-10-01.md" here` — matching the code's own needle
shape, `` `"${dayKey}.md"` ``, not a bare, unquoted mention, which `git

git fixture outside the project (`/tmp/test_s_scope`, removed after) that
`git log -S'"2026-10-01.md"' -- docs/briefings/.sent.json` finds only the
real send-marker commit while the same search scoped to the whole
directory ALSO matches the decoy — exactly the failure mode the mutant
reproduces. New test: "findPreviousBriefingSentAtIso scopes its git log
-S search to .sent.json alone, never the whole briefings directory" —
confirmed it both passes against the real code and fails (reporting the
