# BL-1430 — coder pass, 2026-09-05

## What was wrong

`extension/test/bl874PortableTimeInvariants.property.test.js`'s own
"defined in exactly one file repo-wide" check walks the repo from its
root, excluding `node_modules`, `.git`, `out`, `coverage`, `.stryker-tmp`,
`vendor` — but not `.worktrees`. Every pipeline role's linked worktree
(`.worktrees/QA`, `.worktrees/architect`, `.worktrees/cleaner`,
`.worktrees/coder`, `.worktrees/documenter`, `.worktrees/hardender` — six
on this host) carries a full checkout, each with its own copy of
`specs/pipeline/steps/lib/portableTimeGuard.js`. The walk counted every
one of them as a separate "definition," so a single, correct definition
read as seven. `git grep "function findPortableTimeViolation" --
extension/src specs/pipeline` — the scope a human would actually check —
finds exactly one, confirming the ticket's own diagnosis: the definition
is single, only the walk's scope was wrong. The property's own assertion
was never weakened to make it pass (invariant 1).

## A self-referential bug caught by the post-commit merge re-verify

Scenario 01's own `git grep -l 'function findPortableTimeViolation' -- extension/src specs/pipeline`
initially embedded that exact contiguous phrase directly in the step
handler file's own source (as the grep pattern argument) - and the step
handler lives under `specs/pipeline`, one of the two scanned trees. While
the file was still untracked, `git grep` (which searches the tracked
tree, not the raw working directory) never saw it and the acceptance run
passed. The moment it was `git add`ed and committed, `git grep` started
matching it too, and scenario 01 failed with "found 2" - the step handler
itself and the real guard module. Caught during the routine post-commit
`origin/main` merge re-verify, not before. Fixed the same way
`bl948SocketFixtureShortRootSteps.js`'s own generated-fixture bodies avoid
the identical trap: the pattern is now assembled by concatenation
(`'function ' + 'findPortableTimeViolation'`) so the file's own text never
contains the contiguous phrase it searches for. Re-verified: 2/2 pass,
twice, with the file committed and tracked.
