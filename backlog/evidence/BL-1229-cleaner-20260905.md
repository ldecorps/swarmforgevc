`bl1229PilotGateDepsContractInvariants.property.test.js` and

silently diverge), applied here to its own test-side tooling.

`extension/test/helpers/pilotAcceptanceGateDeps.js` (the file already
established as "the ONE base object" for this ticket's shared contract
knowledge) and exported them; both test files now import from there
instead of each defining their own copy. No behavior change — `jscpd`
confirms 0 clones after the fix; both files' own test suites re-verified
green.
