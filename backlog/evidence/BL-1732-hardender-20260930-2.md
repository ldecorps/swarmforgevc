  `newValues[slot]` (the latter stays exactly as D2's own fix manages
  it) and re-arming `newValues[slot]` when the dropdown's value matches
  the slot's own added value again. Added a regression test (add, switch

  this one new test fails, with an empty `newValues` in the submitted
  body (the precise defect shape) - not a hang or a crash, a clean
