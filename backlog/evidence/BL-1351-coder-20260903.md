# BL-1351 — coder pass (2026-09-03)

## The consumer sweep (invariant 1), in full

Method: every file that opens `/events` (grepped repo-wide for `'/events'`,
`EventSource`, and the SSE route constant), then what each takes off a frame.

| consumer | what it reads off /events |
|---|---|
| `extension/src/bridge/holisticUiHtml.ts` | the state frame. `renderBacklogBoard(state.backlog, …)` renders `item.id + ' - ' + item.title` for `backlog.active` and joins assignments by `item.id`. Also `state.pipeline`, `state.agents`, `state.runLog` — none of them narrowed. `assignments`/`doneByMilestone` come from `/holistic`, not the stream. |
| `extension/src/bridge/bubbleHostUiHtml.ts` | only blocks containing `event: host-activity`; every other block, the state frame included, is skipped (`block.indexOf('event: host-activity') === -1` → return). |
| `extension/src/tools/telegramFrontDeskBotCore.ts` (reply relay) | only records whose event is `telegram-reply` (`record.event !== 'telegram-reply'` → return). |
| `extension/src/tools/telegram-front-desk-bot.ts` | opens the stream and hands it to the relay above. Its backlog data — `notes`, `firstAcceptanceStep`, `approvalContext`, `rulingOptions`, `remainingSlices`, `description` — comes from `readBacklogFolders` on DISK via `toFoldersSnapshot`, never from a frame. |
| `extension/test/bridgeServer.test.js`, `specs/pipeline/steps/bl1350IdleEventStreamKeepaliveSteps.js` | frame framing (snapshot presence, keepalive comments), no per-item field. |

**Union of per-item fields read off the stream: `{id, title}`.** That is what
`STREAM_BACKLOG_ITEM_FIELDS` carries. The sweep is re-derived at run time by
the invariant-1 property: it reads the field population from
`backlogReader.ts`'s own `BacklogItem` interface, asserts each named-event-only
consumer still filters to its own event, and fails if the state-frame consumer
reads any dropped field — so a consumer that grows a read of a dropped field
reds the suite rather than losing a UI section silently.

## Design decision recorded (not left as a side effect)

`buildBridgeState` also feeds the JSON `/state` routes. The projection is
applied at the STREAM producers only (`resolveEventsSnapshot` and
`broadcastSnapshotIfChanged`, both now calling the single
`buildStreamSnapshot`). `/pipeline`, `/agents`, `/backlog` and `/runlog` keep
their full fidelity — `/backlog` is what the holistic UI's own first render
reads, and narrowing it here would be exactly the silent side effect the
ticket forbids. The architect owns the ruling on whether the routes should
follow; this parcel makes the answer explicit and reversible either way.
