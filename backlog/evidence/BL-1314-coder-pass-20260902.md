**The scoping fix itself** is one grep: `'"merge-base".*"--is-ancestor"'` →
`'"merge-base".*"--is-ancestor".*swarmforge-QA'`, matching the shape the bash
sibling already had. Both halves are now scoped by the `swarmforge-QA` ref
name, the only durable anchor for "this call asks the QA question".

**Why a lib rather than an in-place edit of the grep.** Inline in the standing
test, the assertion could only ever be run against the live tree — and the
regression this ticket fixes is not expressible by mutating a checked-in file
in place. Extracted, the same checks can be driven against fixture files, which
is what makes scenarios 01–03, the 9 unit cases and all three properties
executable rather than simulated. The live-tree run stays exactly where it was,
in the standing test, so the manifest reachability the ticket pins is unchanged.

**The known limit is stated, not engineered around** (as directed): a re-inlined
call binding the ref to a variable escapes this pin and its bash sibling
equally. It is deliberately NOT closed with an allowlist of `handoffd.bb`'s
legitimate ancestry calls — a hand-enumerated membership list rots silently
(BL-973 shape) and would fail again on the next helper for a fourth question.
Written into the lib's header comment.

## Declared invariants — encoding and non-vacuity

Both are encoded as executable properties driving the real predicate in bash.
Neither is left unencoded, so no stated-reason clause applies.

| Invariant | Encoding | Generator reach |
|---|---|---|
| 1 — fails when and only when a file answers the QA question outside `is_qa_ancestor.sh` | split into **1a** (1–6 helpers over other ref pairs ⇒ passes) and **1b** (1–3 QA-question helpers, interleaved with noise ⇒ fails, naming only the offending file) | **near misses by construction**: every non-QA ref is derived from `swarmforge-QA` — case-flipped, separator-swapped, truncated, reversed, prefix-only, namespaced — so each helper is a collision candidate. Arbitrary strings would essentially never produce a QA-looking ref, and the property would pass against a matcher scanning for `QA` alone or for any ancestry call. Generator assertions fail the test if a non-QA draw names the QA ref, or if a draw is not an ancestry call at all. |
| 2 — the positive half is not weakened while the negative half is scoped | over (which file loses its `is_qa_ancestor.sh` call × arbitrary other-question helpers): the assertion must fail, name that file, and **not** name the intact one | the intact file keeps its own call in every draw, so a failure that blamed the wrong file is caught rather than passing as "it failed, good" |
