## Invariants checked against the diff

- **Invariant 1** (landed stays a positive finding, never inferred from
  silence): `sibling-path-verdict` returns `:unlanded` whenever `changes`,
  `main-lines`, or `tip-lines` is falsy — an unread diff, an unread blob, and
  a walk-failed/empty-path/unreadable-diff row all still fail closed.
  `sibling-own-line-changes` returns `nil` (never `{}`) when any candidate
  commit's diff could not be read, and that `nil` is scored `:unlanded` in
  `landed-siblings`, not silently skipped.
- **Invariant 2** (a sibling is judged on its own attributed content only):
  `sibling-own-line-changes` filters candidates to the sibling's own commits
  before diffing; `sibling-path-verdict` compares only that sibling's
  surviving added/removed lines against the tip, never the path's whole blob.
  Merge commits are explicitly excluded from a sibling's own line changes
  (their first-parent diff carries the second parent's content, not the
  merging ticket's), which is the mechanism that stopped BL-1341-class
  misattribution.
- `:vacuous` (a path with nothing left for this sibling to land) is dropped
  from the attributed set before scoring, so it can't be misread as either a
  landed or unlanded obstacle — matches the "silence is never scored as
  evidence" contract in the docstring.
