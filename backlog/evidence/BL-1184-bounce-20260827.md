## D1 — rows 1-3 were prose and a glob, not `path::pattern`

As minted:

    - "extension/src/metrics/ deliveryMetrics or shiftVelocity::8h landed counts::git and/or telemetry"
    - ".swarmforge/telemetry/shift-velocity-*.jsonl::optional forward capture::append-only if no existing series"
    - "briefing burndown/email path::shift velocity chart::non-linear time axis"

`pre_qa_gate_lib.bb` matches a pattern as a **plain substring** against the
named file at the commit being sent — there is no expansion step. So:

- row 1's path is an alternation in prose (`... deliveryMetrics or shiftVelocity`)
  naming no file, and its pattern `8h landed counts` is a sentence no source
  line contains;
- row 2's path is a **glob** under `.swarmforge/`, which is gitignored and
  therefore present in no commit at all — unsatisfiable by construction;
- row 3's path is prose (`briefing burndown/email path`).

Row 4 (`specs/pipeline/steps/index.js::bl1184BriefingShiftVelocitySteps`) was
correct and is unchanged.

This is the BL-874 shape the specifier prompt already warns about, repeated:
a `required_wiring` pattern must be a literal that will exist, never a
placeholder or a description.
