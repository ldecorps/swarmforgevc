## A real fixture gap found while building BL-210's scenario 03

`PaneTailer.poll()`'s dead-session detection only fires once a role has
been confirmed LIVE via `liveRoles` - which itself depends on
`refreshRolesForTick()`'s live-tmux role discovery
(`tmuxClient.readLiveSwarmRoles`), a multi-call path a plain
`installInProcessTmux` rule set does not fully satisfy. The existing
class test (`test/paneTailerClass.test.js`) works around this by
temporarily swapping `tmuxClient.readLiveSwarmRoles` for
`tmuxClient.readSwarmRoles` (the static `sessions.tsv` reader) for the
scenario's duration; this handler reuses that exact technique
(`withStaticRoles`), confirmed via a standalone debug run before and
after the swap (dead events absent/present respectively).
