## Defect found and fixed

`discharge-debt` and the new `record-attempt` are structurally
near-identical: both match a row by `(parcel, gate)` via an inline
`(keep-indexed (fn [i r] (when (and (= parcel ...) (= gate ...)) i))
rows)`, both refuse (rows unchanged) on a blank input string or no
matching index. `jscpd` cannot see this (no Babashka/Clojure parser is
registered, so it silently analyzes 0 files rather than reporting "no
duplication" — confirmed by running it against the file alone and
getting a 0-files-analyzed result, not a genuine 0-clones verdict).
Manually compared both functions line by line and confirmed the
row-matching logic is byte-identical apart from variable names.

Extracted the shared match into a private `find-row-idx` helper; both
`discharge-debt` and `record-attempt` now call it instead of repeating
the `keep-indexed` predicate. No behavior change — same matching rule,
same refusal shape, confirmed by re-running every test below unchanged.

This is squarely in scope: both functions were introduced in this same
ticket's own two passes (the original `discharge-debt` and this
amendment's `record-attempt`), with no established external callers to
break by the extraction.
