## One real gap found and closed

**`|| true` dropped** was the third initial survivor, and it is real:
verified empirically (script reverted to test) that a PRESENT-but-crashing
detector, without `|| true`, aborts the whole script under `set -euo
pipefail` — exit 1, empty output, no EDN decision and no refusal marker.
That is worse than either documented outcome: the caller (QA's landing step)
cannot tell it apart from a hang. The existing test suite's only "detector
unrunnable" row (06) makes the detector ABSENT, which the presence guard
short-circuits before `entangled_sibling_report` is ever invoked — so `||
true`'s actual job, catching a crash from a detector that IS invoked, had no
test.

Added unit row 08 to `land_main_publish_test_runner.sh`: a detector file
that is present but throws on load, asserting the shipped code fails open
(exit 0, ordinary decision, no marker) — non-vacuity checked first (the same
fixture with the real detector still doesn't refuse on its own). Confirmed
this row fails when `|| true` is removed, passes with it restored.

## tmpDirMigrationGuard — real regression found and fixed

The whole-tree guard sweep (parcel touches `specs/pipeline/steps/` and
`extension/test/`) flagged a genuine NEW violation, not a pre-existing one:
`extension/test/bl1309LandDecideEntanglementInvariants.property.test.js:69`
used raw `fs.mkdtempSync(path.join(os.tmpdir(), FIXTURE_PREFIX))` instead of
the shared `mkTmpDir()` helper (BL-743's "touched `extension/test/` files
must use `mkTmpDir()`" rule, enforced by a fail-closed whole-tree assertion).
The sibling BL-1354 property test landed the same day and got this right
(`mkTmpDir(FIXTURE_PREFIX)`) — this file simply missed it. Fixed by
importing `mkTmpDir` from `./helpers/tmpDir` and using it in `newFixture()`;
the file's own explicit `try/finally` + prefix-sweep cleanup
(`fs.rmSync(fx.work, ...)`) is unaffected and still runs — `mkTmpDir`'s own
per-test sweep is `force:true` and tolerates the dir already being gone.
Guard now clean (`tmpDirMigrationGuard.test.js`: 12/12 pass).

Observed one non-reproducing flake in the property suite after this fix (1
failure in 17 total runs, 16/16 clean before and after) — real git
subprocess timing under host contention (other worktrees were running
concurrent vitest at points during this pass), not a logic defect; could not
capture the failure detail on a second occurrence despite 16 follow-up runs.
