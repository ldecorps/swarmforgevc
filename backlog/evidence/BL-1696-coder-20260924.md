## What landed

- **`swarmforge/scripts/seat`** (new): the seven verbs (`next`, `done`,
  `ask`, `note`, `handoff`, `merge`, `test`), a per-role table (every
  pipeline role — `coder`, `cleaner`, `architect`, `hardender`,
  `documenter`, `QA` — gets all seven; `coordinator` gets
  `next`/`done`/`ask`/`note`; any other role, including unset
  `SWARMFORGE_ROLE`, gets none). Two roots resolved exactly per the
  ticket's own direction: checkout via `git rev-parse --show-toplevel`,
  project root via the parent of `git rev-parse --path-format=absolute
  --git-common-dir`. Argument validation (role-in-roles.tsv, `BL-<n>`,
  7–40 hex sha that resolves to a real commit object, two-digit priority,
  forbidden-character text) runs BEFORE anything executes; every verb's
  own script/git call receives caller text as its own argv element only —
  no shell string is ever built from it. `handoff` speaks the two-call
  self-audit protocol directly in bash (retries an identical draft once on
  `AUDIT_REQUIRED`, refuses on a second). `merge` runs `git merge --no-ff
  --no-edit`, and on conflict lists the conflicted paths and `git merge
  --abort`s before exiting 3 — HEAD and the merge state are both restored.
  `test` resolves `config seat_test_command` from the effective conf via
  the existing `backlog_depth_conf_path_cli.bb` (same resolution
  `backlog_depth_lib.bb` uses for `active_backlog_max_depth`), degrading
  to "not configured" (exit 2) on any failure to resolve it — never a
  crash. No `mapfile`/`readarray`/`declare -A`; verified stock-bash-3.2
  syntax with `bash -n`.
- **`specs/pipeline/steps/bl1696SeatCommandVocabularySteps.js`** (new,
  required_wiring): drives the real `seat` script (copied verbatim into a
  throwaway fixture repo), never a reimplementation. Scenario Outline
  handlers validate against explicit KNOWN_VALUES (`NONE`/`DRAFT` argv
  sentinels; `EIGHTY_ONE_CHARACTERS`/`A_REAL_COMMIT` token substitutions
  resolved from the fixture's own state), not a passthrough parse of the
  Examples table's display text.
- **`extension/test/helpers/seatFixture.js`** (new): the shared
  throwaway-git-repo fixture (recorder-stub `ready_for_next.sh`,
  `done_with_current.sh`, a stateful `swarm_handoff.sh` that answers
  AUDIT_REQUIRED on request, a babashka `role_ask.bb` stub), used by both
  the acceptance handler and the property tests so the fixture shape is
  defined once. Proves it is a standalone repo (`git rev-parse
  --git-common-dir` under its own realpath) before any mutating git

- **`extension/test/bl1696SeatCommandVocabulary.property.test.js`** (new):

## Invariants (BL-654)

1. **"Every `seat` invocation runs at most the one script or git
   subcommand its verb names, and a refused invocation ... runs nothing
   and leaves the working tree unchanged."** Encoded as a CONSTRUCTED
   catalog of 16 malformed shapes (one per required-argument rule across
   all seven verbs, plus an unknown verb) crossed with every named role
   including unset — 128 combinations, all reached by construction
   (asserted via a reach-floor `Set`, not hoped for), zero recorded script
   calls and an unchanged `git status --porcelain` across the whole sweep.
   Non-vacuity: disabled the note verb's 80-char length check
   (`swarmforge/scripts/seat`) — the property immediately named the exact
   spec/role pair that then ran to completion (exit 0 instead of 2);
   restored, diff empty, re-verified green.
2. **"No caller-supplied argument is ever evaluated by a shell ..."**
   Two tests: (a) four CONSTRUCTED real shell-injection idioms, one per
   forbidden character, each targeting a marker file unique to the
   fixture — refused (exit 2) and the marker never created, for every one
   of the four; a generator drawing arbitrary strings would reach these
   specific characters in an actually-dangerous shape essentially never,
   so they are constructed, not drawn. (b) a randomized `fast-check` sweep
   (60 runs) varying which of the four characters, its position in the
   text, and which field carries it (ask text vs. note message) — always
   refused. Non-vacuity: removed the `$` arm from `seat`'s `text_ok`
   case — both invariant-2 tests immediately failed with the exact
   offending payload named (`char="$" ... text="$"`); restored, diff
   empty, re-verified green.
