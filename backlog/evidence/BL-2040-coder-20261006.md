## What the coder built

Added test 4 to `specs/pipeline/test/bl989PortableGrepTabAnchor.property.test.js`:
a tree sweep that refuses a single-quoted `grep -E` (or `-qE`, `-Ee`...)
pattern containing a literal `\t` in `swarmforge/scripts/**/*.sh` outside
`*mutation_sweep.sh`, plus a fixture probe proving the sweep is not
vacuous. The sweep regex matches a `grep` token followed by an E flag
and a single-quoted pattern containing backslash-t. Before the hotfix
it would have named test_bl1861_local_llm_remove.sh lines 194, 196 and
336; on 6038e612b4 it finds zero.

Note: the first draft of the sweep regex used a single backslash in the
ERE (`\\t` in the JS template literal), which GNU grep reads as a
literal `t` (the same defect the hotfix fixed), causing false positives
on single-quoted patterns containing a literal backslash-t in a
different context. The corrected regex uses a double backslash
(`\\\\t` in the JS template literal), which GNU grep reads as a literal
backslash followed by `t`, matching only the fail-open shape.
