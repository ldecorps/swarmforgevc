## Declared invariants (BL-654)

All three have a coder-authored, non-vacuous property test, each shown to
fail against a deliberately broken implementation (verified live, then
restored — `diff` against a pre-break backup confirmed byte-identical
restoration every time):

- **Invariant 1** (main against the sender's base only, never the parcel
  tip) — **P1**: a real git fixture with `main` and `sender` branches
  sharing one base commit; independently randomizes whether main amends
  the feature file after the base and whether the sender edits its own
  copy; asserts `blocked?` tracks `amend-main?` exactly regardless of
  `edit-parcel?`. Broken by making `gather-and-decide-for-ref` use the
  cited commit as `base` instead of the real merge-base: failed on every
  case where the sender edited its own copy while main stayed untouched
  (`blocked?` wrongly flipped to `true`).
- **Invariant 2** (exactly one reader of the acceptance field) — **P2**:
  randomized ticket-YAML shapes (quoting styles, block-scalar, surrounding
  filler fields, before/after position) asserting
  `findings-for-git-handoff`'s own `:path` always agrees with
  `task-scope-gate-lib/declared-acceptance-path` applied directly to the
  same YAML text. Broken by substituting a naive `re-find` reader with no
  quote-stripping/block-scalar handling: failed on every generated case
  (73/300).
- **Invariant 3** (fail-open is absolute; a refusal is loud) — **P3a**
  drives `decide-for-ref` through all six reachable outcomes (four
  fail-open reasons, refuse, clean) via a category-driven generator with
  fuzzed concrete payloads (base sha, ref, amending-commit hashes), and
  asserts each fail-open reason never produces `:refuse`. Broken by
  deleting the `(nil? differs?)` branch: every `:differs-unknown` case fell
  through to `:clean` instead of `:not-evaluated` (6/300, exactly the
  category's own generated share). **P3b** drives `refusal-message` with
  randomized task names, one shared path (matching the real single-path
  contract), refs, and amending-commit lists, asserting every required
  fact (marker, `HANDOFF_NOT_QUEUED`, path, ref, each commit, remedy) is
  present. Broken by removing the `HANDOFF_NOT_QUEUED` line: failed on
  every generated case (300/300).

**Reachability floors**: all coverage buckets (P1's amend/edit
combinations, P2's has-field/is-block shapes, P3a's six categories)
measured 42-168 out of 300 runs — all well above the 30 (runs/10) floor.
