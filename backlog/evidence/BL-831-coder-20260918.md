## Declared invariants — property tests (BL-654)

`extension/test/bl831BubblePipelineBoardInvariants.property.test.js`, one
property per invariant, against real fixture trees under mkdtemp:

- Invariant 1 ("one board read model..."): for any set of tickets and
  role/stage assignments, every `captureBubblePipelineBoard` row's `column`
  equals exactly `computeLivePipelineBoard`'s own row column for that id.
- Invariant 2 ("main view sufficient..."): every in-flight ticket carries a
  non-empty blurb, for any mix of tickets with and without a description.

Non-vacuity (checked by hand, documented in the file): hardcoded the page's
column assignment to a constant — invariant 1 failed on the first non-matching
fixture. Made the blurb fallback return `''` instead of the title for a
description-less ticket — invariant 2 failed. Both reverted, re-verified
green.
