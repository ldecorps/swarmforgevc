## What changed (user/operator-visible)

`land_step_lib.bb`'s `ancestry-commits` — the sibling detector's candidate
walk behind `entangled-siblings` — drops `--first-parent`, so it now walks
a commit's FULL ancestry. The replay's own-path diff (`:delivered`, from
BL-1297) diffs a merge against its first parent alone and so can draw
content from a second parent regardless of author; a first-parent
detection walk could never reach a commit sitting only on that second
parent, so a sibling ticket whose untagged work rode into a forward-merge
that way had its files enter the replay tip while its id never reached the
sibling report. Observed live on BL-1307's documenter tip `bd27e884cb`,
which carried four unlanded BL-1300 files (human_approval still pending)
past a report naming only BL-1288/1293/1299. `own-commit-changed-paths`
and `task-tagged-changed-paths` are untouched — only detection widened
(shape 1 of the ticket's two offered directions).
