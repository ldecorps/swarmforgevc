# BL-1407 — coder pass, 2026-09-05

`check_property_suite_drift.sh` no longer refuses a commit on ONE run of the
316-file property suite. A non-allowlisted failing file is now re-run once,
alone, before the guard decides: if it passes alone it is a load flake
(recorded, commit allowed); if it fails alone it is a genuine regression
(refused exactly as before, naming the file). This is the guard that
refused five unrelated BL-1370 commits across 2.5 hours on 2026-09-04, a
different file each time, none of them touched by the parcel.

## Declared invariants (BL-654)

All three have a coder-authored, non-vacuous property test in this parcel,
each shown to fail against a deliberately broken implementation (verified
live, then restored — `diff` against a pre-break backup confirmed exact
restoration):

- **Invariant 1** (a deterministic red is always refused) — broken by
  forcing the post-rerun branch to always take the "flake" path
  (`if (( 1 == 1 ))` in place of `if (( rc == 0 ))`): every `:det-red` draw
  failed (incorrectly allowed, wrongly named as a flake) — 2/2 in a 20-run
  sample.
- **Invariant 2** (every cleared flake is recorded durably) — broken by
  skipping `record_flake` on the passing branch: every `:flaky` draw failed
  (commit still correctly allowed, but no record) — 4/4 in the same sample,
  both `touches: true` and `touches: false` represented.
- **Invariant 3** (the re-run is bounded; overrun counts as failure) —
  broken by replacing `run_bounded`'s ceiling check with an unreachable
  threshold (`waited >= 999999`): every `:hang` draw failed BOTH the
  verdict check (the guard incorrectly allowed the commit once the 30s
  fixture sleep finally finished) and the wall-clock check (~30.1-30.2s
  measured, `> 15` threshold) — 2/2 in an 8-run sample; the property
  catches the defect two independent ways.

**Reachability floors**: all three kinds, and for `:flaky` both
touched-by-commit booleans, at least a few times each in the default
45-run configuration (measured 11/11/7/16 across `:det-red`,
`:flaky-touched`, `:flaky-untouched`, `:hang` — well above the 5/2/2/5
floors).
