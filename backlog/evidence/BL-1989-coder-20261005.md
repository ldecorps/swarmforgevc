`hookSpecificOutput.additionalContext` string — no `permissionDecision` or
block field exists anywhere in the hook; it cannot refuse a call. An
unparseable top-level event yields `nil` (no `println`); an unreadable
transcript path is caught and `repeat-note` stays `nil`. Matches the
declared invariant.

- `offset-hint`: fires only on `read_file` with numeric `offset == 1`.
  Correct per description.
- `sleep-hint`: fires on `run_shell_command` matching
  `(^|[;&|]\s*)sleep\s+\d`. Traced by hand against `&&`/`||` chains (the
  second special char in a doubled operator still satisfies `[;&|]`
  directly before the space+digit) and against a command that only
  *mentions* "sleep" in prose (`grep -n sleepy x.log`, no match) — both
  match the test file's own cases.
- `read-hint`: a missing path warns to `git ls-files | grep`; an existing
  file over 300 lines with no limit, or a limit above 300, warns about a
  whole read; a limit ≤300 (at any offset) is silent. Matches description
  and `big-file-lines = 300`.
- `npm-hint`: fires on a command starting with `npm` (optionally leading
  whitespace), never mid-chain after `&&` — narrower than "anywhere in the
  command" but matches the test's own cases and the commit's description.
