# BL-1671: coder pass

## Fix

`swarmforge/scripts/check_merge_deletion.sh` `collect_deletions` now reads
`git diff --cached --name-status -M "$against"` (was `git diff --name-status
-M "$against"`, no `--cached`) - the index against each parent, never the
working tree. Header comment updated to describe the actual read. `-M`
(rename detection, BL-1403), BL-1341's second direction (MERGE_HEAD) and
BL-1662's attribution walk are untouched - the diff read is the only change.
