## Invariants — verified directly in the diff
1. **A stage with no classified turns is absent, never zero.**
   `assembleWindowRecord` maps `series.stages` directly — nothing seeds a
   stage list, so a stage the walker saw no intervals for simply has no
   entry. Confirmed by the invariant-1 property test breaking when every
   trail stage is seeded at zero.
2. **Fail-closed on interior damage; a torn final line is tolerated.**
   `assessTranscriptReadability` classifies a bad line only at
   `lines.length - 1` as `truncatedTail` (readable); any other bad-line
   position, or an unreadable path, goes to `unreadable`.
   `assembleWindowRecord` refuses the whole window (`complete: false`, empty
   `stages`) the moment `unreadable.length > 0`, regardless of
   `truncatedTail`. This exactly matches the specifier's amendment
   (`167d7d5ab5`) ratifying the coder's reading — verified the amendment
   text against the code line by line, not just trusted the evidence's
   characterization of it.
3. **The category set comes from the walker's own definition.**
   `INTERVAL_CATEGORIES` is exported as a runtime tuple from
   `transcriptWalker.ts` (previously a type-only `IntervalCategory`, which
   vanishes at runtime and would have forced every enumerator to restate the
   list — the exact BL-897 drift this invariant forbids).
   `turnProfileProducer.ts` re-exports it as `TURN_PROFILE_CATEGORIES`
   rather than declaring its own list. Confirmed by the invariant-3 property
   test asserting shares sum to 1, which catches an omitted-but-emitted
   category even if the key set were faked.
