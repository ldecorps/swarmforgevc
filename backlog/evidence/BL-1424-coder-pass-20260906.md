## Deviation from the ticket's "How" (direction, not mandate)

The ticket suggests a fixture that copies the guard scripts into the
mkdtemp repo. Both the acceptance feature and the property runner instead
invoke the REAL `check_test_file_registration.sh` (in this repo's own
`swarmforge/scripts/`) with its `cwd` set to the fixture root - no copy at
all. This is the exact pattern `bl1428StandingRedRegisterCli.bb` (BL-1428,
same day, a structurally identical guard) already established: the real
guard resolves everything via `git rev-parse --show-toplevel` (cwd-relative)
and `$SCRIPT_DIR`/`fs/parent`/`*file*` (its own file location), so a copy
adds risk (staleness between copy and original) with no benefit.

## Non-vacuity (BL-654), all three declared invariants

Each break applied by hand to `unregistered_test_gate_lib.bb`, confirmed
via `diff` against a pre-edit backup empty after restore, property runner
green again immediately after each restore.

- **Invariant 1** (commit-scoped, not tree-scoped): `diff-base` changed to
  always return the empty-tree constant (ignoring HEAD), making the diff
  tree-wide instead of staged-only. 7/56 cases failed (every P1 case with
  at least one drift file), each expecting exit 0 (every staged addition
  registered) and getting a refusal naming the DRIFT file instead.
- **Invariant 3** (fail-open): `staged-manifest-rows` changed to return
  `[]` instead of `nil` when the staged manifest could not be read. 8/56
  cases failed (all 4 `:manifest-missing` P2 cases, 2 assertions each),
  each expecting a WARNING + exit 0 and getting a refusal instead (an
  empty-rows manifest is indistinguishable from "no test files registered
  at all", the exact tree-wide-refusal shape fail-open exists to prevent).
- **Invariant 2** (one notion of registered): `parcel-test-file` changed to
  ALSO match `*_property_runner.bb` (a shape `suite-inventory-lib/test-file?`
  explicitly excludes - property runners have their own lane). 3/56 cases
  failed (every P3 case generating a `*_property_runner.bb` name), each
  disagreeing with the independent re-derivation from
  `suite-inventory-lib/test-file?`.
