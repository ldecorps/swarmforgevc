## Root cause confirmation (qa_e2e item 2)

**Site 1** — `extension/src/swarm/backendSwitch.ts:69-74`:
```ts
if (model === 'auto' && agent === 'copilot') {
  model = 'copilot/auto';
} else if (model === 'auto' && agent === 'cursor') {
  model = 'cursor/auto';
}
```
A bare `--model auto` in a `cursor-agent` launch script is deliberately
qualified to `cursor/auto`. `test/backendSwitch.test.js:104` (as it stood)
still expected the unqualified `'auto'`.

**Site 2** — `extension/src/notify/telegramClient.ts:306-321`:
```ts
export async function sendTelegramPoll(
  ...
  allowsMultipleAnswers = false
): Promise<SendPollResult> {
  const body = JSON.stringify({
    chat_id: chatId,
    question,
    options: options.map((text) => ({ text })),
    ...(messageThreadId !== undefined ? { message_thread_id: messageThreadId } : {}),
    is_anonymous: false,
    allows_multiple_answers: allowsMultipleAnswers,
  });
```
BL-568 added `allows_multiple_answers` to the request body unconditionally
(defaulting `false`). `test/telegramClient.test.js:297`'s `assert.deepEqual`
over the whole parsed body did not list it — with `node:assert/strict`,
`deepEqual` is strict, so the extra own key failed it.

**Site 3** — `extension/src/tools/telegramOperatorAmbulance.ts`, the
"BL-691 D3" guard (mirrors `ambulance_lib`'s own engage-refusal): refuses to
engage for a ticket that is not in `backlog/active/`. The BL-698 test's
fixture seeded `backlog/paused/BL-698.yaml` and expected "Ambulance engaged
for BL-698". The sibling test at (then) line 224 (`/hold`, a paused→hold
move) is unaffected by this guard and stays green, which rules out a
broader regression in `executeOperatorVerb`.
