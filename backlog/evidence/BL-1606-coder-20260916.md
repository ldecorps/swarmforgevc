## The fix

`extension/test/helpers/propertyLaneContentionBudget.js`'s
`propertyLaneTimeoutMs(baseMs, opts)` passed no `ceilingMs` to
`resolveUnitLaneTimeout`, so it defaulted to the unit lane's shared
`UNIT_LANE_BUDGET_CEILING_MS` (120000) - a FIXED ceiling under bl968's own
240000 ms base. `effectiveBudgetMs`'s own arithmetic
(`min(ceilingMs, base * max(1, factor))`) then clamped ANY factor >= 1 to
120000, half the declared budget, regardless of load. Proven by hand
(non-vacuity, see below): even `factor` computed from `forks=1, load=0`
(the quietest non-degenerate case) reproduces this for any base above
120000, since `max(1, factor)` floors at 1 and `120000 < base` alone is
enough to clamp.

The remedy: `propertyLaneTimeoutMs` now passes
`ceilingMs: Math.max(UNIT_LANE_BUDGET_CEILING_MS, baseMs * PROPERTY_LANE_MAX_GROWTH)`
(`PROPERTY_LANE_MAX_GROWTH = 3`, the worst contention factor this host has
measured per BL-1579's own evidence) - a base under the shared ceiling
keeps exactly today's arithmetic (the ceiling stays 120000, unchanged),
and a base at or above it gains the same multiplicative headroom every
other base already had. Never a copy of `effectiveBudgetMs`'s math - only
its existing `ceilingMs` injection point.

Both files migrated off a bare per-test timeout onto the helper:
- `bl1304DryRunSpawnsNothing.property.test.js`'s three `test(...)` calls
  (no per-test timeout before, sitting on the lane's flat 20000 ms
  `testTimeout`) now each pass `propertyLaneTimeoutMs(20000)`.
- `bl968MaterializedGuardSensitivity.property.test.js`'s one `test(...)`
  call's bare `240000` third argument becomes
  `propertyLaneTimeoutMs(240000)`, the BL-1450 comment above it kept
  verbatim.

Diff scope (invariant 2): both files' diffs contain only one added
`require` line each and the per-test timeout argument change - no draw
count, reach floor or assertion touched
(`git diff -- extension/test/bl1304DryRunSpawnsNothing.property.test.js extension/test/bl968MaterializedGuardSensitivity.property.test.js`
shows exactly that).
