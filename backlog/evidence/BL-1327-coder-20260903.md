# BL-1327 — coder pass (2026-09-03)

Built to the human's ruling: **proposal-only.** Slice 1 emits a durable
proposal record (who / what / why / candidate notch) and a human applies it by
hand. There is no autonomous model or effort mutation anywhere in this parcel.

## What landed

- **`swarmforge/scripts/descent_ladder_lib.bb`** — the pure decision. Effort
  rungs come from BL-1317's `adapt-effort-ladder` rather than a second copy, so
  a seat cannot be walked onto a rung the climb half has never heard of
  (BL-897). Two functions: `descent-decision` (what to propose) and
  `record-guard-trip` (ladder bookkeeping on a trip).
- **`swarmforge/scripts/descent_review_cli.bb`** — the review. `review <root>`
  reads ladder state and config, asks the lib, and writes
  `.swarmforge/descent-ladder/proposals.json`; `list <root>` prints the standing
  proposals. It has no code path that edits a pack conf or a launch settings
  file — the governance boundary is enforced by the shape of the API, not by a
  comment asking callers to behave.
- **`swarmforge/scripts/install_descent_review_cron.sh`**, wired into
  `install_swarmforge_crons.sh` in this same parcel — the `required_wiring`
  entry, and the point of it: a periodic review nothing schedules is dead code
  (BL-419/BL-1235). Idempotent (a second install replaces this root's line
  rather than adding a second), and skippable with
  `SWARMFORGE_SKIP_DESCENT_REVIEW_CRON=1` like its two siblings.

## The three declared invariants, in the code and in tests

1. **Streak before descent.** A notch is proposed only once `clean-periods`
   reaches the configured threshold at the CURRENT notch. One clean period
   never moves a seat — while a climb takes a single signal (BL-1317). That
   asymmetry is the epic's, kept.
2. **A guard trip discards progress and climbs back.** `record-guard-trip`
   zeroes the streak and returns to the last known-good notch. With no
   known-good notch recorded it leaves the seat where it is: inventing one
   would be exactly the mutation this slice may not make.
3. **Effort before model.** While the current model has a lower effort rung,
   that rung is the proposal. Only when effort is exhausted does a cheaper
   model appear — and it starts at **high** effort, never low, because a
   smaller model may need MORE deliberation; the proposal records that reason
   rather than leaving it folklore.
