# BL-1340 — coder pass (2026-09-02)

Deadlock: promotion refused every `.feature.draft` pointer, including one the
ticket itself was chartered to convert, which no role could clear. 12 live
tickets were stranded, two of them expedited defects.

Human ruling A implemented: **a `required_wiring:` entry naming a
`specs/pipeline/steps` registration is the pin** that marks a draft
self-converting.

## The three changes the ticket directed

1. **`promotion_gates_lib.bb`** — new `pins-draft-conversion?` reads the
   ticket's own `required_wiring:` block (a line walk; `read-field` returns nil
   for a block by its own documented design). `acceptance-executable-refusal`
   now admits a pinned draft and keeps refusing a parked one, with a refusal
   that says WHICH kind: `"... as parked with no conversion pinned, so not
   executable"`. Deliberately narrow — any wiring entry at all would let every
   wired ticket through, so the entry must name the steps directory the
   conversion actually writes to. A pin does not conjure a file: a pinned draft
   that is not on disk still refuses as missing.

2. **`promote_and_route_next.sh`** — `is_buildable()` and the
   `buildable[]`/`other[]` pre-partition are gone; the whole eligible set goes
   to the one chokepoint in one `select` call. The partition ran BEFORE
   ordering, so it silently outranked Article 3.2.4 (invariant 2). Deleting it
   was the smaller change the ticket preferred, and it holds.

3. **`acceptance_contract_gate_lib.bb`** — the exit end. A parcel whose
   acceptance still names a draft at the cited commit is one
   `:acceptance-contract` finding, failing CLOSED, naming the draft and how to
   convert it. Checked BEFORE step resolution on purpose: every step resolving
   is not a rescue, because the runner globs `*.feature` and never executes a
   draft at all. `pre_qa_gate_gather_lib.bb` supplies the fact (`:declaration-draft`);
   the pure gate keeps doing no git or fs. The delegating header comment in
   `acceptance_pointer_gate_lib.bb` is re-tensed to point at its new seat.
