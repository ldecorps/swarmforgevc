# BL-1332 — coder pass (2026-09-03)

Critical: `own-paths` decided per PATH while `write-tree-from-paths!` took the
WHOLE blob, so a file both tickets edited was pulled in by the landing ticket's
ownership and carried the unlanded sibling's lines with it. On 2026-09-02 that
shipped an unlanded `require(...)` into `specs/pipeline/steps/index.js` on
origin/main and the registration guard then refused every role's commit —
backlog bookkeeping included — until a human adjudicated.

## Built to the human's ruling: option 1

`own-paths` gains one branch, ahead of the existing exclusion: a path whose
owners include BOTH the landing ticket AND an unlanded sibling **refuses**,
naming the path, the landing ticket and the sibling(s), and explaining that a
replayed path is taken whole. It never ships either ticket's version.

Deliberately narrow, and the surrounding behaviour is untouched:

- a path owned only by the landing ticket still replays whole;
- a path owned only by an unlanded sibling is still excluded (BL-1315);
- a path attributed to nobody still replays (absence is not evidence);
- a path shared with a sibling that is NOT unlanded still replays — the
  refusal is about unlanded siblings only;
- an unreadable attribution still refuses first, so BL-1272's fail-closed
  posture is intact.

Per-hunk replay is ruling option 2 and a follow-up slice, not this one.
