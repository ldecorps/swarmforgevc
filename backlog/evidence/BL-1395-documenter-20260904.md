## What changed, operator-visible
A new Tier-1 pre-commit/land guard, `check_bb_scripts_load.sh`, probes
every `.bb` script a commit or a land's replayed tree changes with
`bb -e '(load-file ...)'` against the tree under test (never the checking
worktree), naming file/line/symbol on a Babashka SCI analysis failure.
`handoffd.bb` is additionally BOOTED against a fixture root and waited for
one heartbeat, since SCI analysing each `defn` in isolation cannot prove a
forward reference absent — only running the file start-to-finish can.
Wired into both `run_commit_guards.sh` (catches a hand-splice on `main`,
exactly the class of incident that happened) and `land_step_lib.bb`'s
replayed-tree-guards list, as a third sibling alongside BL-1385's
handler-module-graph guard.
