# BL-1502 — coder pass

## Scope

`extension/test/bl1089FrontDeskLivenessFixture.property.test.js`'s
fixture-source test pinned the helper NAME
`stamp_own_heartbeat_then_age_past_stall`. BL-1285 (`9021f12bb2`) renamed it
to `stamp_own_heartbeat_immediately_stale` while keeping the property the
contract exists to guard (the age-0 stamp), so the rename read as a
regression.

Fix: extracted the contract into one shared predicate,
`extension/test/helpers/bl1089FixtureSourceContract.js`
(`checkFixtureSourceContract(text)`), which asserts three rules against
fixture TEXT — never a helper name:

1. `write_heartbeat "$root" 0` is present (the served-then-stopped stamp is
   age 0, not a backdate).
2. `write_heartbeat "$F" 5000` is absent (no predecessor-shaped backdate).
3. `write_heartbeat "$F" 10` is present (the healthy-poll check survives).

The property test's third case now calls this predicate instead of
hand-matching the retired name. `swarmforge/scripts/test/test_front_desk_supervisor_liveness.sh`
is untouched (FIRM per the ticket).

## Invariants (BL-654)

Declared invariant 1: "One implementation of the fixture-source contract:
the property test and the acceptance handler evaluate the same predicate
over the same fixture text, never two hand-written copies of the regexes."

Encoded as a coder-authored executable test in the same property-test file
(`BL-1502/BL-654 invariant 1: property test and step handler share one
fixture-source predicate`) asserting the step handler's source text
`require`s the exact same helper module path this file uses. Not wrapped in
`fc.property` — the invariant quantifies over which module two specific
files import, a closed structural fact with no meaningful generator, not a
value space to sample. Non-vacuity: before the step handler existed this
test failed with `ENOENT` reading it (the file wasn't authored yet); after
authoring the handler with the `require`, it passes.
