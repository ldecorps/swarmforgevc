## What "relays the front desk's own answer" is, mechanically

`extension/src/tools/bubbleSeatLive.ts` drives `processLetsTalkTurn` — the SAME
turn the Let's Talk surface posts to, against the same agent session — and posts
what it returns, unedited. There is no code path in the module that composes a
reply.

That is what makes invariant 1 structural rather than remembered: producing a
divergent answer would require ADDING a path that writes one. The property test
now pins it at the strongest level — for any reply the front desk can return,
the text that reaches the topic is that reply byte for byte.

The one text the seat authors is a REFUSAL, and only when the front desk could
not answer at all (an error, a throw, or an empty reply). That is the intake's
own requirement — "a Bubble seat that cannot answer says why in its own topic;
it never fails silently and never hands the turn to another seat" — and a topic
that goes quiet is indistinguishable from one nobody is watching.

## What this does NOT do, stated rather than implied

**It does not add a second answering worker.** Option 1 was chosen over a paid
dedicated session knowing that, and the specifier's own approval context put the
cost in front of the human. What it removes is Bubble's dependence on the CURSOR
HOST TOPIC's decision path: a Bubble message is now answered from the front
desk's own turn, dispatched before cursor's decision is consulted and without
`ctx.busy` being read at all. The front desk's turn still runs against the
shared agent session, so this is not a parallel brain — saying otherwise would
be claiming a parallelism the code does not have.

`cursorBusy` remains an accepted, deliberately UNREAD input with a test
asserting the turn is byte-identical busy or idle, so the regression this ticket
removes has a name.

## The wiring, which is what failed review last time

The dispatch guard no longer requires an injected function:

    const runTurn = deps.runBubbleSeatTurnFn ?? runBubbleSeatTurn;

That is the sibling BL-1235 seat's own shape (`deps.runLocalSeatTurnFn ??
runLocalSeatTurn`). Requiring the injection is exactly what made the branch dead
in production and cost this ticket its architect bounce — the guard was
unconditionally false in the live bridge.

`bl1296BubbleSeatLive.test.js` now asserts BOTH halves of D1 against the live
source: the topic reader is called, and the turn has a real default.
NON-VACUOUS — reverting either line fails it with the reason named
("the Bubble seat turn has no real default, so the dispatch branch is dead in
production").
